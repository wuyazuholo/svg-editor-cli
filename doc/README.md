## 架构方案（初稿）

采用 TypeScript 面向对象实现，一类一文件。领域层负责六种图形、组合关系和文档不变量；应用层负责会话和历史；命令层使用 Command 模式封装操作；IO 层负责 SVG 编解码和文件读写；CLI 层负责分词、分发和终端交互。

依赖方向：CLI → 命令／应用／IO；命令 → 应用／领域／IO；应用 → 领域；IO → 领域；领域不依赖上层或 Node 文件系统。命令名和图形类型各使用一个注册表，列为下一阶段可改造的扩展点。

编辑在文档深拷贝上执行，成功才提交，并以执行前后快照支持撤销重做。Composite 将组和叶子统一为 Shape；组移动与缩放递归修改后代几何属性。
